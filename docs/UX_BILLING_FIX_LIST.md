完了はコード変更だけではなく、対象環境で受け入れ条件を確認した時点で記録する。

## 表示速度・読み込みUX（2026-10-18）

画像の解像度・圧縮率は今回の対象外。目標は、主画像が見えるまでの不要な待ちを取り除き、周辺機能の準備中も閲覧できる状態にすること。
「ローカル実装」は本番完了を意味しない。以下はすべて未デプロイ。本番・キャッシュなしの受け入れ確認後に完了へ移す。

| 優先 | 修正 | 状態 | 受け入れ条件 |
| --- | --- | --- | --- |
| P0 | 一覧・詳細の画像をJS初期化待ちで透明にしない | ローカル実装・SSRテスト | JS未実行のHTMLでも画像が可視。取得失敗時の候補切替は維持 |
| P0 | 一覧の先頭5枚を遅延取得対象から外す | ローカル実装・SSRテスト | 先頭行はeager、後続はlazy。全作品の一括先読みはしない |
| P0 | 一覧カードの順番待ち登場アニメーションを外す | ローカル実装 | 取得済み画像を最大570msのstaggerやフェードで隠さない |
| P0 | Imagineの作成応答を編集画面へ引き継ぎ、同じデザインの再取得を省く | ローカル実装・単体テスト | 詳細キャッシュを使い、認証スコープ変更時は既存どおり破棄 |
| P0 | Imagineへの遷移を一覧再取得待ちから外す | ローカル実装・単体テスト | 一覧更新が未完了でも編集画面へ遷移できる |
| P0 | Imagineの登場演出終了・中断で透明レイヤーを残さない | 前段でローカル実装・単体テスト | 描画フレーム停止・中断後も位置と透明度が復元される |
| P1 | 詳細の主画像と販売・前後作品パネルを別々に返す | 未着手 | 周辺取得を遅延させても主画像は表示。保存状態・購入権限を保持 |
| P1 | 1作品表示時のシリーズ全体画像・全タグ取得を絞る | 未着手 | キャッシュ未命中時も対象範囲に絞った読取。画像候補・販売導線が一致 |
| P1 | 一覧もタグ集計・シリーズ選択の待ちと主画像一覧を分離 | 未着手 | フィルタ取得待ちでも先頭画像が表示される |
| P1 | 遷移・初期読込は固定寸法の骨組みを表示し、全画面の待機で主画像を覆わない | 未着手 | 遅い通信でレイアウト跳ねなし。準備できた部分から操作可能 |
| P1 | メタデータ失敗／画像失敗／空一覧を分け、対象箇所だけ再試行 | 未着手 | 一部の失敗で表示済み画像を消さない。画面全体のリロード不要 |
| P1 | Imagine画像の取得・decodeに期限を設け、停滞にも再試行を提供 | 未着手 | 永久loadingにならず、正常レイヤーは表示を維持 |
| P1 | Imagineのデータ取得開始を大きいツールUIの読込から独立 | 未着手 | 認証・権限を保ったまま文書取得を先行。未使用モーダル等は必要時読込 |
| P2 | 作品リンクのhover/focus時だけ限定的に遷移先を先読み | 未着手 | 長い一覧を一括先読みせず、意図した遷移の待ちを短縮 |
| P0 | 初回／再訪の画像可視時間と操作可能時間を性能テストに追加 | 一部実装（SSR・待ち合わせ回帰） | 実ブラウザのJS・通信遅延条件でも計測。本番p50/p95と改善前後を比較 |

計測はHTML応答開始、主画像取得開始、画像取得完了、画像可視、操作可能を分ける。既存のAPI 3秒以内テストだけではUX合格にしない。
測定値とコード上の根拠は [ARCHITECTURE_OVERVIEW](./ARCHITECTURE_OVERVIEW.md#structural-performance-audit-2026-10-18-image-quality-unchanged) を参照。

## P0: 決済・会員権限

- [ ] サブスクリプションの全ライフサイクルをSandboxで確認する
  - [x] 別の新規アカウントで契約し、手動操作なしでPremiumへ反映される。
  - [x] Customer Portalで期間終了時の解約を予約し、期間内はPremium権限が維持される。
  - [x] 契約〜解約予約まで、Stripe、Webhook、Supabase、画面表示、コンテンツ権限が一致することを本番テストで確認した。
  - [ ] 期間終了時に自動的に無料会員へ復帰する（解約予約済みのテストアカウントで後日確認する）。このとき `customer.subscription.deleted` が2xx、Supabaseが `free / canceled`、画面とPremium権限が失効状態になること。
- [x] 解約予約をマイページへ確実に反映する
  - 「更新日」ではなく「解約済み（契約期間終了までPremiumを利用できます）」と「利用終了日」を表示する。
  - Customer Portalから戻った時とマイページ表示時にStripeの現在状態を再同期し、再読込・再ログイン後も `canceling` 表示を維持する。
- [ ] Webhookを唯一の反映手段にしない
  - 決済成功画面、マイページ、定期照合から同じ契約同期処理を呼べるようにする。
  - Webhook失敗時に警告し、管理者がStripeから再同期できるようにする。
- [ ] 単品壁紙の購入・ダウンロード・全額返金・権利失効をSandboxで確認する
  - [x] 購入後に壁紙を正常にダウンロードできる。
  - [ ] 全額返金後に購入権限が失効する。

## P1: 認証体験 — クローズ（2026-08-08 本番テスト完了）

- [x] サインインとサインアップを明確に区別する
  - 画面タイトル、説明、主要ボタン、既存ユーザー／新規ユーザーの切り替え導線を見直し、どちらの操作中か迷わないようにする。
- [x] ログイン・サインアップ画面を選択言語に合わせて翻訳する
- [x] メールサインアップ完了を明確な完了画面または完了状態として表示する
  - 入力欄と「アカウント作成」ボタンを残したままにせず、確認メール送信済みであることと次の操作を明示する。
  - 二重送信を防止する。
- [x] メール確認リンクから戻った後の再ログインをなくす、または最小化する
  - セッションを確立できる場合はログイン済みで戻す。
  - できない場合も、確認完了とログインへの次の操作を明確にする。
- [x] 認証メールのブランドをIMAGINEからWHATIFへ統一する
  - 送信者名、件名、本文、リンク先を確認する。
